# Annotation compatibility warning

The provisional manual-overfitting figures in this directory were generated
from annotations of the former IP-Adapter Plus scale-0.7 outputs. On
2026-10-12, all 192 main-experiment IP-Adapter images were replaced using
scale 0.3. Consequently, the IP-Adapter values and all-method aggregates in
these figures are stale and must not be used for the current benchmark.

The DreamBooth, DreamBooth-LoRA, and Textual Inversion source images were not
changed. Regenerate these figures only after the current IP-Adapter images have
been reannotated.

The newly added non-personalized base-model control also has no ratings in the
old four-method annotation set. Any five-method manual comparison requires new
ratings for both the current IP-Adapter outputs and the base-model outputs.
